# 직접 입력 공간

`직접입력.csv` 는 직접 입력 양식이에요(공개 저장소에는 빈 양식만 있어요). 엑셀로 열어서 아는 칸만 채우면 돼요.

- **주요 성분**: 한글이나 영어로, 쉼표로 구분 (예: `나이아신아마이드, 병풀, 세라마이드`)
- **전성분**: 제품 뒷면이나 올리브영·화해에서 복사한 전성분 그대로
- **사진**: 제품 사진 주소(있으면)
- **메모**: 자유롭게

채운 파일을 스레드에 올리면 Claude가 `apply_manual.py` 로 반영해요. 성분 라벨 사진만 올려도 대신 읽어서 채워요.
목록에 없는 제품도 줄을 추가하면 돼요(상품코드는 엑셀의 바코드).
직접 입력한 내용은 웹 조사 결과보다 우선해요.
