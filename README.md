# 오프뷰티 성분 노트

명동 오프뷰티 매장 직원이 **손님의 국적·피부 고민·최신 트렌드**에 맞춰 제품을 더 정확하게 추천하도록 만든 도구입니다.
매일 아침 사람 손 없이 해외 뷰티 트렌드를 모으고, 매장 제품 추천 화면까지 갱신합니다.

## 1. 문제
- 명동 매장은 손님 대부분이 외국인이고, 나라마다 찾는 성분과 고민이 다릅니다.
- 손님이 "여드름", "펩타이드 크림", "밤에 바르는 팩"처럼 말하면, 아르바이트생은 어떤 성분이 맞는지, 매장 어디에 있는지, 어떻게 설명할지를 그 자리에서 떠올려야 합니다.
- 해외에서 무엇이 뜨는지 매일 찾아볼 시간이 없습니다.

## 2. 해결
**손님의 말 → 필요한 성분 → 매장 제품 → 진열 위치 → 설명**까지 3번 터치 안에 도달하게 했습니다.

| 화면 | 하는 일 |
|---|---|
| 추천 찾기 | 검색어(한/영/오타)를 고민·피부·제형·성분으로 해석해 매장 제품을 적합도순으로 보여주고, 진열 위치와 효능 설명을 함께 표시 |
| 성분 사전 | 매장 제품에 든 성분을 한국어/영어로 설명 |
| 트렌드 | 나라별 인기 TOP 10 (조회수·좋아요·댓글 종합), 영상에서 화제가 된 매장 제품은 "인기급상승"으로 상단 표시 |

추천 규칙: 적합도 = 고민 ×3 + 피부 타입 ×2 + 제형 ×2 + 사용 시간 ×1 + 국가 트렌드 ×1. 민감성 피부에 강한 성분(AHA/BHA·레티놀)은 ⚠️ 표시.

## 3. 매일 자동으로 돌아가는 흐름
```
07:20  유튜브 공식 API로 7개국 K뷰티 영상 수집 (무료 할당량 안에서만)
07:52  합치기(merge_day.py) → 사이트 만들기(build.py) → 추천 페이지 데이터 갱신(store/make_page_data.py)
       → 이 저장소(사이트)와 노션 보고서에 반영
```
PC가 꺼져 있어도 클라우드에서 실행됩니다.

## 4. 설계에서 신경 쓴 점
- **비용 0원**: 유료 API·유료 수집 서비스를 쓰지 않고, 할당량 증액도 요청하지 않습니다.
- **매장 정보 비공개**: 진열 위치·가격·상품 목록은 이 공개 저장소에 없습니다(`store/.gitignore`). 직원용 비공개 페이지에만 들어갑니다.
- **추측하지 않기**: 확인 못 한 성분은 "미확인"으로 두고, 직접 입력 양식(`store/manual/`)으로 채웁니다.
- **단순한 코드**: 라이브러리 없이 순수 HTML/CSS/JS, 파일 하나에 일 하나.
- **AI 활용**: 기획부터 데이터 정리, 코드, 매일 자동화까지 Claude와 함께 만들었습니다. 작업 기준은 `CLAUDE.md`에 있습니다.

## 5. 폴더 구조
| 위치 | 내용 |
|---|---|
| `index.html`, `sw.js`, `manifest.json` | 매일 갱신되는 트렌드 사이트 (휴대폰 설치형) |
| `store/` | 추천 찾기 화면 코드와 데이터 스크립트 (설명은 `store/README.md`) |
| `CLAUDE.md` | 작업 기준과 결정 기록 |
